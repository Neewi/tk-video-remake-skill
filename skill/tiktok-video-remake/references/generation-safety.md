# 年轻人物描述与美式本地化规范

本规范避免最终生成提示中出现过于直接的儿童描述，同时防止人物被统一成年化而偏离源片。核心原则是：**以原片感觉为主，只把明显儿童标签最小替换为青少年或高中生，并统一使用美国选角与美式场景。**

## 1. 源片记录

- `原视频脚本（只读参考）`只写画面中可观察到的年龄外观，不推断人物真实年龄。
- 明显年幼时写“明显儿童外观的人物”；无法判断时写“年龄外观不确定的人物”，不要擅自写具体年龄。
- 不从源片外观推断人物真实族裔、国籍或身份；原视频脚本照实记录可见画面，不把生成选角混入源片事实。
- 源片中的教室、卧室、校园走廊、家庭关系、服装、动作和镜头语言都属于可观察事实，不因后续生成适配而改写。

## 2. BASE 与变体的人物适配

- 源片人物明显具有儿童外观时，校园语境写“高中生”，其他语境写“青少年”；不写具体年龄、`18 岁以上`、`成年人`或其他会推动成熟外观的标签。
- 改写后继续保留年轻的面部比例、发型轮廓、服装颜色与风格、动作、姿态、角色关系、构图、机位、口播、音频和节奏。
- 源片人物已明显为成年人时，保持对应成年年龄感，不统一年轻化或成熟化。
- 年龄外观不确定或接近边界时，不做大幅外形改造，选择最贴近场景的“青少年”或“高中生”。
- BASE、变体和所有新增人物均作为虚构角色处理。每个主要人物首次出现时固定写成“美国白人”或“美国黑人”；多人和背景人群可由美国白人与美国黑人共同组成，不出现亚洲面孔。
- 不因肤色或年龄描述添加刻板化行为、职业、服装或社会背景。

## 3. 场景美式本地化

- 保持源片场景的功能、空间关系、人物关系、动作路径、构图和镜头语义，只调整可见环境风格。
- 客厅、卧室、厨房和家庭院落使用当代美式住宅装修与陈设。
- 街头、社区、商圈和停车区域使用可信的美国城市或郊区视觉语言。
- 教室、走廊、体育场和校园空间使用美式高中环境，不改成大学、办公室或成人培训机构。
- 其他可识别场所使用对应的美国建筑、家具、标识尺度和公共空间风格；避免无关地标和夸张刻板符号。

## 4. 阶段一审核文件

只有实际发生年轻人物描述适配时，才在基本信息中增加一行：

```markdown
- 生成描述适配：将明显儿童外观人物调整为青少年或高中生，保持年轻感以及原有关系、动作、构图和节奏。
```

基本信息再用一行写明：虚构人物采用美国白人/黑人选角，所有环境按原场景功能做美式本地化。在 BASE 对应镜头中固定每个主要人物的选角与“青少年/高中生”标签；变体默认继承，只有改变人物阵容时才重写。

不要在每个镜头反复解释平台政策，也不要输出大段安全声明。

## 5. 宫格与视频提示词

- A1/A2/B1/B2 中的同一人物必须保持相同的美国白人/黑人选角、年轻程度、发型和服装；不得在其他格恢复成明显幼童，也不得突然变成成熟成年人。
- 年轻人物适配只改变必要的生成标签，不借机改变关系、剧情、表演或镜头语义。
- 有人物时，在 Symphony 提示词的“人物外观锚点”中逐个固定主要人物的选角与稳定外观，例如：`主角为美国黑人高中生，中等身材，黑色短卷发，穿深蓝色连帽衫，保持年轻自然的高中生外观；其他可见人物为美国白人或美国黑人，不出现亚洲面孔。`
- 无人物时明确写：`画面中不出现人物。`
- 最终生成提示词允许使用“青少年”“高中生”“teenager”“high school student”；不使用“儿童、小孩、小朋友、婴儿、幼儿、未成年”以及 `child / kid / baby / toddler / minor` 等直接儿童标签。避免单独使用“男孩/女孩/少年/少女”或 `boy / girl` 这类年龄边界含混的角色标签。
- “人物外观锚点”必须明确人物选角、稳定发型/体型/服装和表演气质；“环境视觉锚点”必须明确美式环境的稳定风格、材质主色、光线和环境元素。“禁止”部分简短写“不出现亚洲面孔，不生成幼童外观”，不要写 18 岁年龄下限。

## 6. 冲突处理

- 源片或用户要求直接使用儿童、小孩或婴幼儿标签时，不把这些标签带入生成稿；提出最小替代方案：“保留原场景、关系、动作与镜头感觉，仅将人物描述为青少年或高中生。”
- 若核心创意无法在青少年或高中生设定下成立，阶段一用一个简短阻塞问题让用户决定，不擅自重写整个创意。
