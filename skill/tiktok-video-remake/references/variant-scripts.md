# 原样脚本与可控变体规范

## 1. 分支模型

阶段一同时提供一个独立可执行的原样脚本和若干变体覆盖层：

- `BASE`：完整的“复刻执行脚本（原样复刻，独立可执行）”，不依赖任何变体内容。
- `V01`、`V02`……：以 BASE 为母版，只覆盖明确写出的差异；未写出的内容全部继承 BASE。
- 变体母版只定义所有变体共同的继承与允许修改规则，不改变 BASE。

默认生成正好 5 个差异明确、可执行的变体：

- `V01–V03`：3 个 `M2｜保钩子中变体`。
- `V04–V05`：2 个 `M3｜大变体`。

用户本轮明确指定其他数量或配比时服从用户。否则不得减少、增加或调换默认配比，不得为了凑数量生成近义重复方案。

使用以下统一语言：

- **钩子骨架**：前 3 秒事件顺序、冲突/反差/悬念机制、商品首次有效出现时点、核心动作、情绪曲线、节奏峰值和关键切镜。
- **转化内核**：目标受众问题、商品在剧情中的作用、核心利益、商品证明方式、整体情绪强度和 CTA 意图。
- **结构轴**：钩子表达、叙事视角、人物关系、场景—动作系统、信息揭示顺序、动作调度、商品入画方式或镜头组织。
- **配套轴**：服装、非商品道具、灯光、环境氛围、局部机位、声音强调等为主变化服务的视觉/听觉维度。

## 2. 人类审核文件结构

在 `script-review.md` 的原样脚本之后、商品事实边界之前使用以下结构：

```markdown
# 变体母版

- 全部分支固定继承：商品身份、商品事实、已证实声称、目标受众问题、核心利益、商品证明作用、整体情绪强度和 CTA 意图。
- M2 固定继承：钩子骨架、完整口播、时间码、核心动作目的、主要音频节拍和切镜逻辑。
- M3 允许重构：钩子表达、叙事视角、人物关系、场景—动作系统、镜头顺序、必要口播和时间分配；所有变化必须显式覆盖并重新校验事实与时长。
- 全部分支继续遵守：美国白人/黑人虚构选角、美式场景、年轻人物统一使用高中生描述，以及商品替换和生成安全规则。
- 未明确覆盖的内容全部继承“复刻执行脚本（原样复刻，独立可执行）”。

## V01｜<短标题>

**差异等级**

M2｜保钩子中变体 / M3｜大变体

**保护项**

<M2 写明保留的钩子骨架；M3 写明保留的转化内核、情绪强度和商品证明作用。>

**主要变化**

<一句话说明相对 BASE 改了什么。>

**变化轴**

- 主变化轴：<结构轴。>
- 配套变化轴：<M2 至少一个配套轴；M3 写第二个结构轴，可再加必要配套轴。>

**逐镜覆盖**

- S01：<写清执行画面、动作、构图、运镜或音频的覆盖值；改变口播或时间码时给出完整替换值。>
- S02：<只写变化；没有则不列。M3 的受影响镜头必须给出足以独立合成的完整覆盖。>

**必要适配**

<说明变化对空间、动作连续性、声音或时长造成的最小适配；没有则省略。>

**保持不变**

<列出本变体明确保护并继续继承 BASE 的内容。>
```

每个变体必须有“差异等级、保护项、主要变化、变化轴、逐镜覆盖、保持不变”。不要机械复制完整 BASE；M3 若影响大部分镜头，必须宁可写完整覆盖值，也不能依赖含混的概括让阶段二自行发挥。

## 3. M2｜保钩子中变体

- 完整保留钩子骨架、转化内核、口播、时间码、核心动作目的、情绪曲线和主要切镜逻辑。
- 使用“一个主变化轴 + 一个配套变化轴”。主变化轴从人物关系/人群组织、场景载体、动作调度/商品入画方式、镜头组织中选择；配套轴必须服务主变化。
- 变化至少覆盖一半视觉镜头；全片只有 1–2 个镜头时覆盖全部视觉镜头。覆盖指镜头中的人物组织、场景、动作调度、商品入画或镜头组织发生可见变化，不是只改形容词。
- 同一 M2 内允许场景变化引发必要的人物位置、动作路径、道具和环境声联动，但不改变事件因果和核心动作目的。
- 单独更换演员肤色、服装颜色、发型、灯光色温、背景装饰或微小机位，不构成合格 M2。
- 成片目标：静音看第一帧能看出不同版本；看完前 3 秒仍能立即认出与 BASE 相同的钩子机制和冲击节奏。

## 4. M3｜大变体

- 完整保留转化内核、商品事实、已证实声称、目标受众问题、核心利益、商品证明作用、整体情绪强度和 CTA 意图。
- 至少改变两个结构轴，其中一个必须来自钩子表达、叙事视角、人物关系或场景—动作系统；另一个从信息揭示顺序、动作调度、商品入画方式、镜头组织或必要口播中选择。
- 变化至少覆盖三分之二视觉镜头；全片只有 1–2 个镜头时覆盖全部视觉镜头。
- 允许重构前 3 秒钩子的表达方式、镜头顺序、人物关系、场景与动作路径，并允许为新结构改写必要口播和时间分配；不得改变目标问题、商品承担的解决作用、核心利益和整体冲击强度。
- 所有受影响镜头必须写出可直接合成的完整覆盖值；改写口播时给出逐字替换，改动时间码时给出新时间范围，并在执行前重新校验时长。
- 不得把 M3 写成 M2 的加强形容版，也不得发展为与源片转化内核无关的新剧情、平静测评、长篇解释或不同情绪基调。
- 成片目标：第一眼和 BASE 是不同创意执行；完整看完仍能辨认它们服务同一个受众问题、商品证明逻辑和情绪冲击目标。

## 5. 五个变体的组合与去重

- `V01–V03` 的主变化轴必须互不相同；优先从人物关系/人群组织、场景载体、动作调度/商品入画方式、镜头组织中选出最适合源片的三种。
- `V04` 优先重构叙事视角或人物关系；`V05` 优先重构钩子表达或场景—动作系统。若源片不适合该轴，选择其他结构轴，但两者不得使用同一核心创意。
- 美国白人/黑人选角、美式场景本地化、高中生描述和目标商品替换是全局要求，不计入任何变体的主变化轴或配套变化轴。
- 任意两个变体不得只通过演员肤色、服装、不同美式房间、灯光或形容词区分；如果一句话无法说清两者不同的事件组织或视觉执行，视为近义重复并重做。
- 生成完五个变体后内部检查配比、覆盖量和重复度；人类审核文件不输出自检过程。

## 6. 通用设计边界

- 描述源片人物时不得推断真实身份或族裔；生成分支中的人物是虚构选角，必须明确为美国白人或美国黑人，不出现亚洲面孔。同一人物跨镜头保持同一选角。
- BASE 已做的人物描述适配默认由所有变体继承。变体新增或替换年轻人物时，统一写“高中生”，不要写具体年龄、`18 岁以上`、`成年人`，也不要恢复成直接儿童标签。
- 所有变体场景保持美式本地化；不因肤色、性别、年龄外观或其他群体特征增加刻板化服装、行为、职业或社会背景。
- “哄抢”等动作保持非暴力的争相拿取或抢购热潮，不擅自加入推搡、受伤、破坏、恐慌或违法行为。
- 变体不得虚构商品价格、性能、稀缺性、评价、使用效果、库存、卖点或戏剧冲突。
- 变体若修改台词、时间码、商品声称、CTA、核心动作或镜头语义，必须显式写入逐镜覆盖，并在执行前重新进行事实和时长检查。

## 7. 选择口令

本节只适用于 `REVIEW_INCREMENTAL`。阶段一文件开头明确告诉用户：

```markdown
> 请直接修改“复刻执行脚本”或任意变体；每次只执行一个脚本。
> 修改后回复“继续原样脚本”或“继续 V01/V02…”；完成一个分支后仍可继续其他分支。
```

将以下表达归一化：

- `继续原样脚本`、`继续原样复刻`、`继续 BASE` → `BASE`
- `继续 V01`、`执行 V01`、`继续变体一` → `V01`
- 其余编号按同样规则映射。

没有任何变体时，单独回复“继续”继续兼容为 `BASE`。存在一个或多个变体时，单独回复“继续”属于歧义，只问一个最短问题：“请指定继续原样脚本，还是 V01/V02/……？”不得自行猜测。`REVIEW_INCREMENTAL` 每次只执行一个分支。

## 8. 重新读取与合成

`REVIEW_INCREMENTAL` 收到明确选择后，或 `DIRECT_BATCH` 按交付计划轮到某个分支时：

1. 重新读取磁盘上的整个 `script-review.md`。
2. 选择 `BASE` 时，只使用当前“复刻执行脚本（原样复刻，独立可执行）”，忽略变体母版和所有 Vxx。
3. 选择 `Vxx` 时，以当前 BASE 为完整母版，叠加当前变体母版规则和该 Vxx 的明确覆盖项，形成该分支的有效执行稿。
4. 不把其他变体内容混入所选分支，不覆盖用户修改的审核文件。
5. 检查所选分支是否存在、覆盖项是否清楚、商品事实是否有依据、动作是否可实现、台词是否能自然说完，并运行该分支的时长校验。
6. 每次只把当前分支送入阶段二；`DIRECT_BATCH` 完成后再顺序处理下一个分支。

## 9. 分支交付

每个分支使用独立目录：

```text
02-storyboard/<BASE-or-Vxx>/
03-symphony/<BASE-or-Vxx>/
```

`REVIEW_INCREMENTAL` 中，一个分支完成后不结束整个 run；说明已完成的分支，并列出审核文件中尚可继续的 BASE/Vxx。用户之后选择其他分支时，重新从磁盘读取审核文件并增量生成，不覆盖已完成分支。

`DIRECT_BATCH` 中，一个分支完成后按 `references/run-modes.md` 自动进入下一个未完成分支，不等待用户口令；六个分支始终分别生成、校验和保存，不把多个分支混成一次阶段二输入。

若用户在某个分支完成后修改了 BASE 或变体母版，后续分支使用最新磁盘内容；先前已经生成的分支保持原样，不自动追溯更新。发现审核文件版本与先前交付不同时，简短说明这一点。
