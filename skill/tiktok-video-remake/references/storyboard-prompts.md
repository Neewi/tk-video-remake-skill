# 宫格分镜与 Symphony 单条提示词规范

本规范每次只处理用户明确选择的一个 `BASE` 或 `Vxx` 有效执行稿。不得把其他分支的人物、场景或覆盖项混入本次输出。

## 目录

1. 关键状态与宫格规格
2. B1 宫格生成与转化张力
3. 宫格检查与裁剪
4. 提示词参考图契约
5. 单条 Symphony 提示词
6. 音频生成
7. 最终自查
8. 交付后的视觉迭代

## 1. 关键状态与宫格规格

从批准脚本提取视觉关键状态，而不是一个镜头只取一张：

- 首帧钩子。
- 人物拿起、展示或放下商品的起止状态。
- 手部与商品复杂交互。
- 保护套、配件、包装的关键形态。
- 真实切镜前后的接力构图。
- CTA 手势和最终停留画面。

布局选择：

- 1–6 个必要状态：6 宫格，3 列 × 2 行。
- 7–9 个必要状态：默认 9 宫格，3 列 × 3 行。
- 10–12 个必要状态：12 宫格，4 列 × 3 行。

不足格数时用相邻动作阶段补足，不添加源片不存在的新场景或新卖点。第 1–2 格优先承载批准脚本的前 3 秒钩子，首格必须具有单一、明确的注意力中心，避免平淡空镜或尚未开始的准备动作。

## 2. B1 宫格生成与转化张力

源视频关键帧默认是人物、场景、构图、动作、光线和非商品道具的锚点；所选 Vxx 的明确覆盖项优先于源帧中的人物、场景、服装、环境和非商品道具。产品资料库图片始终是平板、配件、包装和套装身份的锚点。

使用图像编辑/生成能力只制作一张完整的 B1 转化张力宫格：

- 输出到 `02-storyboard/<script-id>/storyboard-grid-b1.png`；一次生成完整宫格，不要逐格生成或拼接最终分镜，不生成 A1、A2 或 B2。
- B1 的格数、编号、关键状态、时间线语义、人物、场景、目标商品和非商品道具必须与所选有效脚本一致。
- B1 在不改变批准脚本语义的前提下强化前 3 秒主体可见性、商品进入前景的大小对比、关键动作瞬间、景别落差、动作轴和构图方向；若 Vxx 已改变人物或场景，必须使用变体值，不能把源片人物或场景带回画面。
- 视觉强度必须有层次。通过相邻格的中景/特写变化、动作起点/接触/结果状态和硬切前后构图反差表达快节奏，不让所有格都使用相同近景、夸张表情、倾斜构图或极端视角。
- 每个格子是单一、完整的竖屏 9:16 视频关键帧，不在一个格子内拼接多个动作。
- 人物外观、发型、服装、场景布局、光线和非商品道具匹配所选有效执行稿；未被 Vxx 覆盖的部分继续匹配对应源帧。B1 只能在批准动作范围内强化表现。
- 每个主要人物按有效执行稿固定为美国白人或美国黑人，跨格不得改变；多人和背景人物只由美国白人与美国黑人组成，不出现亚洲面孔。选角是虚构生成约束，不用于推断源片人物的真实族裔或国籍。
- 源片人物若有明显儿童外观，无论场景均呈现为年轻自然的高中生；保留年轻面部比例、关系、服装风格、动作、构图和节奏，不写 18 岁以上或成年人，也不把外观推向成熟。
- 所有家庭内景呈现可信的当代美式住宅装修，街头呈现美国城市或郊区街景，校园呈现美式高中环境；其他场所使用对应美国环境，同时保持源片场景功能、空间关系和镜头语义。
- 把源平板、配件、保护套和包装准确替换成批准 SKU；不得残留粉色、颜色、摄像头、接口或包装等源商品特征。
- 使用平板正面/背面/透视图锁定实物身份；使用独立配件图锁定配件；使用包装图只锁定包装。
- 保留批准脚本中的动作和接触关系。目标商品无法完成源动作时，返回阶段一解决冲突，不在宫格中即兴改动作。
- 不得为视觉冲击扭曲商品比例或结构、遮挡必须识别的商品特征，或新增破坏、跌落、争吵、夸张结果、随机文字、速度线和爆炸特效。
- 格子编号 `1–N` 放在边框或留白，不覆盖人物、商品、字幕或 CTA。
- 宫格中不写长段说明，不添加随机文字、Logo、水印或新广告语。

可以内部重试整张 B1 直到通过检查；最终只交付一张合格 B1，不输出失败版本或额外备选图。

## 3. 宫格检查与裁剪

逐格检查：

- 格数、顺序和编号正确。
- B1 的格号语义、动作阶段和时间线映射符合所选有效脚本。
- B1 确实提高关键节点张力，但没有改写批准语义。
- 同一人物跨格一致。
- 所有主角、群演和背景路人的美国白人/黑人选角均符合执行稿，且没有亚洲面孔。
- 高中生跨格保持年轻自然的年龄感，没有恢复成明显幼童，也没有变成成熟成年人。
- 家庭、街头、校园和其他可识别环境均符合对应的美式场景设定。
- 场景、人物、服装和非商品道具符合所选 BASE/Vxx；B1 的构图变化仅限本规范允许的转化张力强化。
- 平板颜色、前后摄、边框、接口和扬声器孔匹配目标产品图。
- 触控笔、保护套、包装及其数量匹配各自参考图。
- 包装外观没有污染实物颜色；实物图也没有改写包装。
- 手指、笔尖、保护套折叠和商品接触关系自然。
- 不残留源商品，不新增未批准配件。

检查失败时重做整张 B1，不输出失败版本。

默认不生成裁剪图。只有用户明确要求单格素材时才运行：

```bash
python3 scripts/crop_storyboard_grid.py 02-storyboard/<script-id>/storyboard-grid-b1.png 02-storyboard/<script-id>/crops-b1 --cells 9
```

裁剪图不是默认交付，不主动创建或展示。

## 4. 提示词与视觉输入契约

Symphony 提示词必须在两种输入方式下使用同一份文本：

- 使用 B1 宫格时，宫格加强构图、景别、人物站位和动作瞬间。
- 不使用宫格、只配合产品图时，人物、环境、画面和声音仍由文字锚点与完整时间线自足定义。

硬规则：

- 提示词不得引用产品图文件名、编号或上传顺序，也不得把人物、环境、商品身份或时间线绑定到不确定的图片编号。
- 把目标商品的颜色、结构、摄像头、边框、配件、保护套和包装身份直接写成明确、自足的文字约束；产品图只加强外观身份，不承担人物、环境或剧情定义。
- B1 的格数、编号与时间线语义必须和提示词一致。
- 人物外观锚点和环境视觉锚点只写与 B1 一致的稳定事实；具体构图、景别、站位、瞬时动作和表情由 B1 加强，不得在文字锚点中另设冲突值。
- 每段时间线必须独立写全场景、人物、动作起点/过程/结束和摄影机语义；宫格编号只能附加在时间段后作为增强定位，删除宫格编号后句意仍完整。
- 提示词可直接对视频模型写：`输入中存在宫格分镜时，按格号加强具体构图、景别、人物站位和动作瞬间；没有宫格分镜时，严格按下列文字锚点与时间线生成。`
- 上述规则不得扩展为上传流程、文件管理或面向用户的交付话术。

### 人物外观锚点

有人物时，为每个主要人物使用稳定称谓并用一句话写清：

- 美国白人或美国黑人选角，以及与剧情有关的年龄感/角色身份。
- 体型或身高感、脸型或最显著的非敏感外观特征、发型与发色。
- 上装、下装、鞋履的款式和主色；只有真正可见且需连续的配饰才写入。
- 人物关系和说话/表演气质用短语说明。

只描述跨镜头保持不变的外观，不写精确站位、临时姿态、瞬时表情、景别、画面占比或与某一张宫格独有构图绑定的细节。背景人群只需说明构成、服装范围和行为状态，不逐人建立角色卡。无人物时写“画面中不出现人物”。

### 环境视觉锚点

每个主要场景用一至两句话写清：

- 场所功能和对应的美式环境类型。
- 装修/建筑风格、主材质与主色、时间与光线。
- 2–4 个跨镜头持续出现的环境元素或非商品道具。
- 真实 UGC 所需的空间质感和环境氛围。

不写只有单张宫格才成立的左右位置、精确距离、家具坐标、主体占比或固定景别。场景存在多个区域时用稳定名称区分，具体站位和摄影机路径放入时间线。

## 5. 单条 Symphony 提示词

输出 `03-symphony/<script-id>/symphony-prompt.txt`。它是一段可整体复制的纯文本，对应一次生成整条视频。允许使用短标题和换行提高可读性，但不要包含 Markdown 代码围栏、审核记录、批准编号、制作流程、QA、后期剪辑或文件管理说明。

固定结构：

```text
生成目标
生成一条 <时长> 秒、9:16、<帧率> 的真实 TikTok 带货视频，一次完成全部画面和音频。

视觉参考
输入中存在宫格分镜时，按第 1–N 格加强具体构图、景别、人物站位和动作瞬间；没有宫格分镜时，严格按下列文字锚点与时间线生成。
宫格只作为时间线关键帧，不要输出宫格、分屏、边框或格号；最终输出始终是单一全屏竖屏视频。

人物外观锚点
<逐个用稳定称谓写清选角、年龄感/角色身份、体型、主要面部或发型特征、服装主色与款式、必要配饰、人物关系和表演气质；只写跨镜头不变特征，不写站位、姿态、瞬时表情、景别或画面占比>

环境视觉锚点
<逐场景写清美式场所类型、装修/建筑风格、主材质和主色、时间与光线、2–4 个稳定环境元素及 UGC 氛围；不写精确家具坐标、主体占比或固定景别>

商品身份
<直接写明平板、摄像头、颜色、边框、接口、配件、保护套和包装的身份约束；不得绑定可选参考图>

完整画面与音频时间线
0.0–X.X 秒｜宫格第 1–2 格
画面：<明确场景和人物称谓；写全起始状态、动作过程、摄影机、切镜和结束状态，删除宫格编号后仍可独立执行>
口播：<逐字台词>
声音关系：<人物同期声/画外音、口型、环境声、BGM、音效>

X.X–Y.Y 秒｜宫格第 3–4 格
...

全局音频
<说话人、语言、语气、语速、音量、环境声、BGM 情绪和相对音量、音效>

禁止
<只列最关键的视觉和音频失败模式>
```

提示词必须：

- 明确真实硬切时间；附带宫格编号时确保编号与时间区间对应。
- 描述动作起点、接触过程和结束状态，而非只写风格词。
- 要求宫格只作为增强参考，最终视频不能出现宫格或编号；不使用宫格时仍按文字锚点与时间线完整生成。
- 不引用外部图片编号或文件名；平板实物、配件和包装身份全部写成自足的文字约束。
- 全文直接面向视频生成模型，不出现上传流程、依赖说明、文件管理或面向用户的交付话术。
- 保留批准脚本的完整逐字台词和 CTA。
- 只使用目标商品支持的声称。
- 必须包含“人物外观锚点”；有人物时逐个固定主要人物的选角、稳定外观、服装和表演气质，并写明其他可见人物只由美国白人与美国黑人组成、不出现亚洲面孔；无人物时明确写“画面中不出现人物”。
- 明显儿童外观的源片人物统一使用“高中生”或 `high school student`，不得写成 18 岁以上或成年人；同时不得出现“儿童/小孩/婴幼儿/未成年”或 `child / kid / baby / toddler / minor` 等直接儿童标签。
- 必须包含“环境视觉锚点”，明确美式场所类型、稳定装修/建筑特征、主色材质、光线和持续环境元素。
- 文字锚点只写与 B1 一致的稳定事实；具体站位、姿态、瞬时表情、构图、景别和主体比例不在锚点中另设值，避免与 B1 冲突。
- 避免堆砌流程性负面词；禁止项只保留最可能破坏成片的 5–10 项。

## 6. 音频生成

Symphony 在同一次生成中完成全部声音：

- 人物出镜讲话时，口型、表情、停顿和手势与逐字台词同步。
- 产品特写中延续同一说话人的声音作为画外音，不突然换音色或声场。
- 描述可观察的语言、语气、语速和情绪，不声称复制真实人物身份。
- 环境声匹配场景并保持较低音量，不盖过口播。
- 源片没有明确 BGM 时明确写“不要添加音乐”；有 BGM 时描述情绪、节奏、进入时间和相对音量。
- 点按、书写、开合和转场音效只在源片存在或人工批准时生成，避免夸张。
- 检查台词字数能在目标时长内自然说完；过长时返回阶段一让人工压缩，不自动加速或删词。
- 不依赖后期配音、源音轨替换或剪辑修复。

## 7. 最终自查

- 是否正好交付一张合格 B1 宫格和一段 Symphony 提示词，且没有生成 A1、A2、B2 或默认裁剪图？
- B1 是否使用批准 SKU，且没有源商品残留？
- B1 的格数、编号、关键状态和时间线语义是否符合所选有效脚本？
- B1 中的主要人物是否固定为美国白人或美国黑人，背景人物是否没有亚洲面孔？
- 高中生是否保持贴近源片的年轻感，没有恢复成幼童或被推向成熟成年人？
- 家庭、街头、校园和其他可识别场景是否已按原场景功能完成美式本地化？
- B1 是否在不改变批准语义的前提下形成更强的钩子、景别落差和画面张力？
- 提示词是否对应一次整条视频生成，而不是多个镜头任务？
- 提示词是否没有外部图片编号、产品图文件名、上传顺序或缺图依赖，并能在没有宫格时独立执行？
- 提示词是否完全没有“本提示词”“唯一依赖”“必传”“用户”“上传”“可选参考图”“推荐参考图”“文件名”“已批准/未批准”“审核”“事实边界”“交付”等人类工作流元话术？
- 提示词是否明确禁止输出宫格/分屏？
- 提示词是否明确美国白人/黑人选角、不出现亚洲面孔，并在无人物视频中声明“画面中不出现人物”？
- 提示词是否包含简洁、跨镜头稳定的“人物外观锚点”，且没有写入会与宫格冲突的精确站位、姿态、景别或画面占比？
- 提示词是否保持高中生年轻形象、避免 18 岁以上或成年人声明，并且没有直接儿童标签？
- 提示词是否明确对应的美式家庭、街头、校园或其他美国环境？
- 提示词是否包含“环境视觉锚点”，写清稳定风格、材质主色、光线和环境元素，但不固定家具坐标或构图？
- 完整画面、口播、口型/画外音、环境声、BGM 和音效是否都写入同一时间线？
- 是否删除了 QA、回传片段、后期剪辑和成片步骤？

最后运行确定性校验，不得跳过：

```bash
python3 scripts/validate_symphony_prompt.py 03-symphony/<script-id>/symphony-prompt.txt
```

只有输出 `PASS` 才能交付。

## 8. 交付后的视觉迭代

本分支首次交付不等待人工批准。只展示 B1 宫格与 Symphony 提示词，并用一句话说明：B1 是转化张力型宫格，可加强构图稳定性；不使用宫格时提示词也可配合产品图独立使用。如需修改，请指出“B1、第几格、具体问题”。

收到视觉反馈后：

- 重做并替换整张 B1，不单独交付某一格；只针对用户指出的问题修改，尽量保持其他格不变。
- 新 B1 继续使用相同格数、编号、时间线语义和转化张力方向，仍保存为 `storyboard-grid-b1.png`，不新增备选版本。
- 若反馈仅涉及穿帮、颜色、结构、人物一致性、手部、构图或画面质感，不重写 `symphony-prompt.txt`。
- 只有反馈改变镜头语义、时间码、台词、商品事实或格号映射时，才同步更新并重新校验 Symphony 提示词。

本分支完成后，列出 `script-review.md` 中仍可选择的 BASE/Vxx，并提示用户可继续另一个分支。不得自动生成其他分支，也不得覆盖其他分支的目录。
